# Heartbeat Checklist

## On Wake
- [ ] Read memory/WORKING.md for ongoing tasks
- [ ] Send heartbeat to Mission Control
- [ ] If task in progress, resume it

## Periodic Checks
- [ ] Mission Control for @mentions in comments
- [ ] Assigned tasks
- [ ] Activity feed for relevant discussions

## Before Sleep
- [ ] Update memory/WORKING.md with current state
- [ ] Send heartbeat idle to Mission Control
